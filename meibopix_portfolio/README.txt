SARVESH TALEGAONKAR — PERSONAL PORTFOLIO

Open index.html in your browser. There is no build step or framework dependency.
For a local server, run this command from this folder:

    python -m http.server 8000

Then open http://localhost:8000.

FILES
index.html     — Resume-based profile, projects, experience, education, and contact
styles.css     — Responsive layout, visual design, and print styling
script.js      — Neural visual, project filters, case studies, menu, copy email
assets/        — Locally hosted fonts, favicon, and actual MeiboPix preview
Sarvesh_Talegaonkar_Resume_Final_1.pdf — Original downloadable resume

CONTENT
Profile details, project descriptions, internship dates, dataset counts, education,
and LinkedIn URL are based on the supplied resume. The MeiboPix screenshot was
captured from the public homepage on 9 October 2026. The other project graphics
are conceptual workflow illustrations, not model outputs or measured results.

EDITING
Update profile and contact information in index.html. Project modal descriptions
are in the projectDetails object in script.js. If the email address changes,
update it in both files. Update internship dates and availability as needed.

HOSTING
Upload this entire folder to a static host, preserving the assets folder and PDF.
Choose this folder as the site's root. No install or build command is required.

ACCESSIBILITY
Includes keyboard navigation, native project dialogs, a mobile menu, skip link,
filter announcements, reduced-motion support, and an animation pause control.
Core content is available with JavaScript disabled. Fonts and preview imagery
are local; the portfolio does not need third-party scripts or trackers.

Font licenses and attribution are included in assets/font-licenses.txt.
