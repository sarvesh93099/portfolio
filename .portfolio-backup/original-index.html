MeiboPix — Meibography Analysis System

An AI-based workflow for eyelid and meibomian gland image segmentation, designed to support visual analysis of meibography images. A research and portfolio project, not a substitute for clinical diagnosis.

From image to interpretable segmentation

MeiboPix brings together deep learning and image processing to identify anatomical regions of interest in meibography imagery. The project reflects work in dataset preparation, image annotation, model training, and application integration.
